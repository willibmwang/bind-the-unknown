What “AlphaFold DB” served the provenance of the counts above 54 models · 0 from AlphaFold

Every structures.predicted row above is labelled AlphaFold DB · 3D-Beacons and reports a bare predicted_model_count, which reads as though AlphaFold modelled these proteins. It did not. The tool reports the host that served each model separately from the tool that computed it, and for these accessions the two disagree: of 54 predicted models, 35 were served by the AlphaFold host and 0 were computed by AlphaFold — they are ColabFold v1.5.2 models, which run the same weights behind a different alignment pipeline. The chain record cannot carry this, because its summariser reduces the model list to a count on purpose; it is read here from runs/predicted_models.json.
