From an accession to ranked targets

What happens between one line of input and the deliverable. This is the shape of the pipeline for any virus, with nothing specific to one genome in it.

Identification needs a relative. A protein is named by matching it against reviewed viral entries. Delete the close relatives and the pipeline does not quietly get worse. It stops.
What it cannot name, it keeps. An unidentified protein stays in the list carrying its own sequence, so a genuinely novel target is not lost between steps.
The count never shrinks. Every chain that is ranked gets a row at every later step, measured or refused with a stated reason. A step may refuse a candidate; it may not drop one.
The ranking ends here. The box above is the last one that decides anything. The two steps after it measure the chains this one ordered, and neither feeds the score that set that order.

Two further steps hang off the ranked list and are shown on the front page, in this order. Every chain inside a 400-residue ceiling is folded from its own sequence by ESMFold. Then each one's surface is measured, on a deposited structure where one covers the chain, and on those predicted coordinates where none does. For a target nothing has solved, there is no other route to a surface. The two answers are reported apart and never pooled.

Neither of them selects anything. A pipeline whose last two steps were swapped invites the reading that the swap changed what gets picked. It did not. The five weights are fixed before the run and none of them is a fold or a surface term, so the order of the list is settled at the box above and nothing downstream can reach it. Both steps record that in the run as a changes_any_rank false, next to what they measured. What the swap changed is what can be measured at all. Folding used to run after the measurement that needed it, so the one case this project exists for was unanswerable by construction. That case is a protein nobody has solved a structure of.

The ceiling decides who can be rescued. A chain longer than 400 residues is never sent to the folding endpoint, so if nothing deposited covers it either, it finishes the run with no surface by any route. On the SARS-CoV-2 walkthrough nearly half the chains sit over that ceiling, all three spike pieces among them, along with the polymerase, the helicase and the papain-like protease. That is a cost control, not a finding about those proteins, and the run record counts them, names them and says per chain which limit closed which route.

And the library definition reads nothing any of this measured. It takes an initiator, a randomised-region length and a set of building-block classes, all three properties of the display platform rather than of a target, so the same library comes out whatever the surface step found. There is no stated rule that turns a measured patch into any of those numbers, and putting an arrow there on an invented one would read as a result. That leaves the step that measures the surface, today, as the one step here whose output nothing reads, recorded as an empty list in the run rather than drawn as an edge.
